### What is LatencyFix?

LatencyFix is an audio plugin that enables remote collaboration for producing audio, enabling remote workflows for musicians and producers without the need for travelling or being on the same room. LatencyFix enables remote workflows, through its two versions available:

**Latency Fix BASIC features:**
Ideal for producers and musicians aiming to collaborate remotely creating music.
- Precise latency measurement between two remote sessions (f.e. a producer and a musician in different places).
- Producer can monitor live recording from a remote Musician together with his own local audio and midi tracks, adjusting for latency on the receiving audio. This allows the producer to hear the Musician's recoding live, on tempo.
- Receiving audio track is adjusted or moved to the correct position on the arrangement, after Musician finished playing.

**Latency Fix PRO features everything on BASIC, plus:**
- Standalone plugin that allows measuring external hardware or studio latency, for custom or more complex setups.
Aimed for producers that not only want to collaborate, but also work with complex hardware setup and studios, where latency needs to be measured for adjustment with other tools.

**Notes:**
- In case you own a license already, please make sure to download the correct version (BASIC vs PRO) and the correct subscription (M-Monthly or Y-Yearly).
- In case you have a free trial, please install "LatencyFix PRO - Monthly" (LatencyFix.PRO.-.LatencyFix.-.Mac.X.Y.Z.M.pkg), since that is the variant that features the free trial licenses.
- Please check the website for necessary specs on your machine. For the moment, only MacOS is supported, as well as ProTools, Ableton and Reaper DAWs.
