### Which products are available at LatencyFix?

LatencyFix offers an audio plugin suite that enables remote collaboration for producing audio, enabling remote workflows for musicians and producers without the need for travelling or being on the same room. LatencyFix enables remote workflows, through its three products available:

**LF Remote (full solution for producers) and LF Musician (streaming only):**
Ideal for producers and musicians aiming to collaborate remotely creating music. LF Remote includes all the features below, while the LF Musician is a simple version of the plugin that Musicians to stream their own audio. The features included in LF Remote are:
- Precise latency measurement between two remote sessions (f.e. a producer and a musician, or the same producer from two different places).
- Producer can monitor live recording from a remote Musician (or his own equipment) together with his own local audio and midi tracks, adjusting for latency on the receiving audio. This allows the producer to hear the Musician's recoding live, on tempo.
- Receiving audio track is adjusted / nudged to the correct position on the arrangement, after Musician finished playing.

For the workflow to work, you will need an audio streaming software (f.e. Audiomovers - not included).

**LF IO:**
- Standalone plugin that allows measuring external hardware or studio latency, for custom or more complex setups.
Aimed for producers that not only want to collaborate, but also work with complex hardware setup and studios, where latency needs to be measured for adjustment with other tools.

Additionally, releases include the following files:
